# Branding Guide: Mesum Ali - Software Engineering Student
### Premium "Deep Charcoal & Gold" Palette (2026)

This document provides the exact color codes and design principles used in your portfolio to help you create consistent, high-impact posts for LinkedIn and other platforms.

---

## 🎨 Color Palette

| Name | Hex Code | Selection | Usage |
| :--- | :--- | :--- | :--- |
| **Sunglow Gold** | `#F5D76E` | Primary Accent | Main headers, branding (Ali), primary buttons, and icons. |
| **Platinum** | `#E5E5E5` | Secondary Text | Descriptions, sub-titles, and metadata. |
| **Deep Charcoal** | `#0A0A0A` | Surface | Card backgrounds and navigation bars. |
| **Midnight Black** | `#050505` | Background | Main site background for maximum contrast. |

---

## 📝 Typography Rules

1. **The "MesumAli" Effect:** 
   - Always pair **Light** and **Bold** weights.
   - Example: `Mesum` (Regular/Light) `Ali` (Gold + Bold).
2. **Taglines:** 
   - Use uppercase with high letter-spacing (e.g., `0.3em`).
   - Example: `SOFTWARE ENGINEERING STUDENT`.
3. **Hierarchy:**
   - Headings: Gold or White.
   - Body Text: Platinum (#E5E5E5) at 70% opacity.

---

## 📸 Social Media Post Tips (LinkedIn/Google/Microsoft)

### 1. Image Backgrounds
Use a deep charcoal background with a very subtle gold glow in the corner (Opacity 5%). This mimics the "AI" vibe of your portfolio.

### 2. Post Graphics
- **Headlines:** Use `#F5D76E` (Gold).
- **Shapes:** Use "Pill" shapes (fully rounded) for any tags or buttons in your graphics.
- **Contrast:** Always use white or gold text on dark backgrounds. Avoid using pure black text.

### 3. LinkedIn Banner Idea
- **Background:** Gradient from `#050505` to `#0A0A0A`.
- **Text (Left side):** `MesumAli` (in the Light/Bold style).
- **Tagline (Below name):** `Software Engineering Student | Full Stack & AI`.
- **Accent (Right side):** A subtle, blurred gold circle (`#F5D76E`) at 10% opacity.

## 🛠 Usage in CSS (Tailwind)

If you need to add these colors to a new project:

```js
// tailwind.config.js
module.exports = {
  theme: {
    extend: {
      colors: {
        gold: '#F5D76E',
        platinum: '#E5E5E5',
        charcoal: '#0A0A0A',
        midnight: '#050505',
      },
    },
  },
}
```
